# Code of Conduct

StageMesh contributors and maintainers must provide a respectful, inclusive,
harassment-free environment in project spaces.

## Expected behavior

- Be constructive, specific, and patient.
- Respect differing experience, identities, viewpoints, and accessibility needs.
- Focus criticism on ideas and observable behavior, not people.
- Protect private information and follow responsible security disclosure.
- Accept moderation decisions and correct harmful behavior promptly.

Harassment, discrimination, threats, sexualized attention, deliberate intimidation,
doxxing, repeated disruption, and publishing another person's private information
are unacceptable.

## Enforcement

Report conduct concerns privately to the repository owner through the GitHub
profile. Do not place sensitive conduct reports in public issues. Maintainers may
edit or remove content, close discussions, reject contributions, issue warnings,
or temporarily or permanently restrict participation. Reports will be handled as
privately and consistently as practical, without promising a particular outcome.

This policy applies in repository spaces and when someone officially represents
the project in public spaces.
