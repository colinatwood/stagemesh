# StageMesh support

StageMesh is pre-1.0 open-source software and currently has no guaranteed support
or production service-level agreement.

For reproducible bugs, use the GitHub bug template. For scoped proposals, use the
feature template. Include the exact version or commit, operating-system version,
installation path, relevant sanitized logs, and whether real hardware was involved.

Do not use public support channels for vulnerabilities; follow
[SECURITY.md](SECURITY.md). Do not upload credentials, signing material, private
session data, copyrighted media, hardware serial numbers, or proprietary plugin
binaries.

CI and packaged test artifacts are engineering evidence. They do not establish
physical-hardware compatibility, accessibility conformance, signing/notarization,
legal approval, or fitness for show-critical use.
